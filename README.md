# PlainApp MD3

An unofficial fork of [PlainApp](https://github.com/plainhub/plain-app) that only adds
**Material Design 3 / Material You dynamic color**.

## English

Everything else is identical to upstream; the upstream README is the single source of truth:

➡️ **https://github.com/plainhub/plain-app#readme**

- **One change only:** adds Material You (wallpaper-based dynamic color) on Android 12+, toggleable in
  *Settings → Dark theme*, falling back to the original colors when off. Nothing else is modified.
- **Upstream updates:** this fork tracks `plainhub/plain-app` and stays as close to upstream as possible.
  All credit belongs to the original author.
- **iOS:** not provided. Android only.
- **License:** AGPL-3.0, same as upstream.

Fork repository: https://github.com/GitHubonline1396529/plain-app

## 中文

PlainApp 的非官方分支，**仅新增 Material Design 3 / Material You 动态取色**。

除此之外的一切与上游完全一致，以上游 README 为唯一权威说明：

➡️ **https://github.com/plainhub/plain-app#readme**

- **唯一改动**：新增 Material You（基于壁纸的动态取色），Android 12+ 可用，可在「设置 → 深色主题」中开关；
  关闭后回退到原配色。除此之外不做任何修改。
- **跟进上游**：本分支持续跟进 `plainhub/plain-app`，除动态取色外尽量与上游保持一致，一切归功于原作者。
- **iOS**：不提供，仅 Android。
- **许可证**：AGPL-3.0，与上游相同。

分支仓库：https://github.com/GitHubonline1396529/plain-app
